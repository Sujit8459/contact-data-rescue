# Contact Data Rescue

A data processing project for cleaning, validating, transforming, and organizing contact and operational data from CSV files into a structured and reliable dataset.

## Overview

This project focuses on processing contact data and improving its quality by identifying inconsistencies, handling missing or invalid values, removing duplicate records, and producing clean, structured output data.

The goal is to transform raw operational data into a format that is easier to use, analyze, and maintain.

## Key Features

- Reads and processes contact data from CSV files
- Cleans and standardizes data
- Handles missing and invalid values
- Identifies duplicate records
- Validates contact information
- Transforms raw data into a structured format
- Produces cleaned and reliable output data

## Data Processing Flow

```text
Raw CSV Data
     ↓
Data Loading
     ↓
Data Cleaning
     ↓
Data Validation
     ↓
Data Transformation
     ↓
Duplicate Handling
     ↓
Clean Structured Dataset
```

## Technologies Used

- Python
- Jupyter Notebook
- Pandas
- CSV Data Processing
- Data Cleaning and Validation

## How to Run

1. Open the Jupyter Notebook in this repository.
2. Make sure the required Python libraries are installed.
3. Provide the required input CSV file.
4. Run the notebook cells in order.
5. Review the processed and cleaned output.
